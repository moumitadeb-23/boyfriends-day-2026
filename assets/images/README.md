# Photos

Replace the sample files with your own photos, or add new photos and update `config.js`.

Recommended:
- JPG or PNG
- 1200px+ on the longest side
- Keep file names simple (letters, numbers, hyphens)
- Use relative paths such as `assets/images/our-first-date.jpg`

Photos uploaded through the editor are stored locally in IndexedDB for the current browser/device only.
